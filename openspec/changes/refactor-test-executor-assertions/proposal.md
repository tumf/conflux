# 提案: テスト実行基盤(Executor)のアサーション・リファクタリング

## 背景
`src/parallel/tests/executor.rs` には248箇所の `unwrap/expect` が存在し、ファイルサイズも3359行と巨大です。
現在のテストアサーションは脆く、一部のテストが失敗すると他のテストの実行やデバッグに影響を与える可能性があります。

## 目的
- `src/parallel/tests/executor.rs` にある脆い `unwrap/expect` をより堅牢なアサーションマクロやエラーハンドリングに置き換える。
- 失敗時のエラーメッセージを明確にし、テストのデバッグ効率を向上させる。
- 大規模なテストファイルでのパニックを減らし、安定したテスト実行を保証する。

## 影響範囲
- `src/parallel/tests/executor.rs` 内のテストケース
