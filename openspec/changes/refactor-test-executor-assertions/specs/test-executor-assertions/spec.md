# 仕様: テスト実行基盤アサーションの堅牢化

## 概要
テスト基盤 (`executor.rs`) におけるエラーは、プロセス全体のパニックではなく、明確なテスト失敗メッセージとして報告されなければならない。

## 期待される振る舞い
1. テスト中に不正なデータや予期しない状態に遭遇した場合、直接 `unwrap` してパニックを起こすのではなく、失敗した理由が分かるエラーメッセージとともにテストが失敗(Fail)する。
2. エラーメッセージには、アサーションの期待値と実際の値が含まれている。

## テストシナリオ (Regression Prevention)
- **シナリオ:** 不正な入力データを与えてエグゼキュータを初期化するテスト
  - **手順:** 存在しないパスや不正なフォーマットのデータをエグゼキュータに渡す。
  - **期待結果:** `unwrap` によるパニックが発生するのではなく、初期化エラーとして `Result::Err` が返され、対応するアサーションが適切なエラーメッセージを出力して失敗する。
