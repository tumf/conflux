- Scope boundary found during apply: the TUI's Space-key and `x` execution-mark writes are not `TuiCommand`s. They are classified by frontend guards and drained by the runner straight into `OperatorCommandService::apply_execution_mark`, so they set the shared store without publishing an accepted-command outcome and reach `/api/v2` only when a later event republishes the projection. Converging them means moving mark classification behind the coordinator, which this proposal leaves to the separate bulk/parallel-control work; the bulk parity comparison therefore stops at shared decision state and says so in `src/tui/command_handlers/cross_adapter_tests.rs`. Every path that *is* a command — including remote `set_execution_mark` and both queue-intent commands — publishes and converges.
