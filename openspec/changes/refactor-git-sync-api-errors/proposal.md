# 提案: APIレイヤ (git_sync) のエラーハンドリング改善

## 背景
`src/server/api/git_sync.rs` には151箇所の `unwrap/expect` が存在し、ファイルサイズは1973行です。
API ハンドラーでパニックが発生すると、サーバーのクラッシュや予期しないレスポンスを引き起こし、システムの可用性に重大な影響を与えます。

## 目的
- `src/server/api/git_sync.rs` 内の `unwrap/expect` を安全なエラーハンドリング（Resultの伝播）に置き換える。
- 発生したエラーに対して、適切なHTTPステータスコードとエラーメッセージをクライアントに返すようにする。
- サーバーの安定性とAPIの可用性を高める。

## 影響範囲
- `src/server/api/git_sync.rs` 以下の API エンドポイント
- 関連するエラーレスポンス構造体
