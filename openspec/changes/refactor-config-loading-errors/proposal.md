# 提案: 設定ファイル読み込みエラーの堅牢化

## 背景
`src/config/mod.rs` には128箇所の `unwrap/expect` が存在し、ファイルサイズは2165行です。
設定のロードはアプリケーションの起動時や再読み込み時に不可欠であり、パニックは起動プロセスの失敗や、意図しないクラッシュを招きます。

## 目的
- `src/config/mod.rs` における `unwrap/expect` を削除し、`Result` を利用した安全な設定のロード処理にリファクタリングする。
- 設定パースエラーやI/Oエラーを、アプリケーション初期化時や呼び出し元へ安全に伝播させる。
- 詳細なエラーメッセージを提供し、設定の誤りを修正しやすくする。

## 影響範囲
- `src/config/mod.rs` およびその設定を利用する各モジュール
