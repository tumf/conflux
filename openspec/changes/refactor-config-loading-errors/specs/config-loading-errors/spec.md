# 仕様: 設定ロードエラーの安全化

## 概要
設定データのパースや読み込み中の問題はパニックを起こさず、呼び出し元に適切なエラー型として伝播しなければならない。

## 期待される振る舞い
1. `src/config/mod.rs` 内で定義された設定ファイルのロードメソッドは、不正なフォーマットやファイルの読み取り失敗時に `Err` を返す。
2. エラーメッセージには、どの設定キーやファイルパスに問題があったかの情報が含まれる。

## テストシナリオ (Regression Prevention)
- **シナリオ:** 欠落した必須キーや不正な型の値を含む設定ファイルからのロード
  - **手順:** 不正なフォーマット、またはパース不能なデータを持つ `conflux.toml` (または該当する設定ファイル) を準備し、`Config::load` メソッドを呼び出す。
  - **期待結果:** ロード処理が `unwrap` によるパニックを起こさず、`ConfigError` 等のエラー型を返し、プログラムが異常終了しないこと。
