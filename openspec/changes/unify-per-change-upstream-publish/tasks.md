## Final Validation

Archive validation itself is the authoritative final OpenSpec validation gate.
Expected archive gate: `cflx openspec validate unify-per-change-upstream-publish --archive-gate`

Repository quality gates expected before acceptance: `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test per_change_upstream`, `cargo test upstream_integration`, and `cargo test --features heavy-tests --test e2e_git_worktree_tests per_change_upstream`. Tests exceeding one second remain behind `heavy-tests` and do not enter the default suite.
