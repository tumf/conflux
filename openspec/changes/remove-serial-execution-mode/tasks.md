The fix waits for `cflx-orchestration-owner.json` to publish the spawned owner's PID before probing once, so no probe can take the lock; the conflict-rejection assertion is preserved. The function body itself was untouched by this change (no diff hunks against base `552fc5e0`), so the race is pre-existing; it is repaired here only because the finding's declared verification is `make test` remaining green, which was unobservable while the suite deadlocked.
