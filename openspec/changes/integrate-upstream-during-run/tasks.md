## Final Validation

Archive validation itself is the authoritative final OpenSpec validation gate.
Expected archive gate: `cflx openspec validate integrate-upstream-during-run --archive-gate`

Repository quality gates expected before acceptance: `cargo fmt --check`, `cargo clippy --all-targets --all-features -- -D warnings`, and `cargo test upstream_integration`.
